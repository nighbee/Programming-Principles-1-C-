# Programming Principles I — C++

Coursework repository for Programming Principles I, implemented in C++. The project contains the course exercises and examples organized under the `C++/` directory.

## Tech stack

- **C++**
- Core programming fundamentals
- Functions, control flow, data structures, and problem solving
- Standard C++ library

## Repository structure

- `C++/` — programming-principles exercises and source code

## What this project demonstrates

- Translating algorithmic problems into C++ programs
- Practicing variables, control flow, functions, arrays, strings, and basic data structures
- Building a foundation for object-oriented and algorithmic programming
- Organizing coursework by topic or assignment

## Getting started

Install a C++ compiler such as `g++` or use an IDE configured for C++. Open the relevant source file in `C++/`, compile it, and run the resulting executable.

Example:

```bash
g++ path/to/program.cpp -std=c++17 -o program
./program
```

The exact compilation command may vary by assignment.
